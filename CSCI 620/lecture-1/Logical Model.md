
Foreign keys
- relate two entities using each other's primary keys

structured query language(SQL)
- data definition language
	- create, drop, alter
- data manipulation language
	- insert, update, delete, select
	- CRUD(create, retrieve, update, delete)

## Types

Strings
- CHARACTER(n) - This has to be exactly n characters db may add buffer to fill the rest
- VARCHAR(n) - This can contain upto n characters
Number
- INTEGER - number
- FLOAT - decimal 
	- DECIMAL(N,P) - N is total digit, P is digit right of the decimal point
Dates
- DATE - YYYY/MM/DD
- TIME - HH:MM:SS:mmmm
- TIMESTAMP - both of DATE and TIME
