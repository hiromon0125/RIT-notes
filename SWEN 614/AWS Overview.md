## AMI
- golden master that provides the information required to launch an instance of any size
- can launch multiple instances from a single AMI when you need multiple instances with the same configuration
- virtual machines are created from a templates known as an Amazon Machine Image(AMI)
- provides the information required to launch an instance
- you can **not** share the instance of the EC2 or services but you can share the image!
