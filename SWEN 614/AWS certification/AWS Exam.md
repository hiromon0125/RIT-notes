
Exam format:

4 domains:
1. Cloud Concepts(28% of the exam)
	1. define AWS Cloud and value proposition(ch. 1, 12)
	2. identify aspects of AWS Cloud economics(ch. 1, 12)
	3. List cloud architecture design principles(ch. 1,9,10,11,12)
2. Security(24%)
	1. AWS Responsibility model(ch. 4)
	2. AWS Cloud Security and compliance concepts(ch. 5,6,8,10)
	3. AWS access management capabilities(ch. 5,8,10,11)
	4. resources for security support(ch. 3,6)
3. Technology(36%)
	1. methods fo deploying and operating in the AWS Cloud(ch. 6,7,8,9,10,11,12)
	2. AWS global infra(ch. 4,10)
	3. core AWS services(ch. 6,7,8,9,10)
	4. resources for technology support(ch. 3)
4. Billing and Pricing(12%)
	1. Compare pricing models for AWS(ch. 2,7)
	2. recognize various account structures in AWS billing(ch. 2,7)
	3. Resources available for billing support(ch. 2,3,6)
