## Trusted Advisors

visually confirms where the account resource configs are sound and compliant
there are also false positives, so do not blindly follow recommended configurations

Categories:
- Cost Optimizations
	- report underutilized or inactive resources
- Performance
	- report config issues that runs suboptimally
- Security
	- report any failures to use security best-practices
- Fault Tolerance
	- identifies resources that are vulnerable to service disruptions due to misconfig
- Service Limits
	- reports resource use that is reaching usage limits
